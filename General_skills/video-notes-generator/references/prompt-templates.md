# Prompt guidance for the reviewing Agent

These are writing references, not templates automatically injected by the Python script. Follow SKILL.md for the active workflow.

Read complete timestamped transcript chunks and actual visual evidence. Organize the notes around the video's topics or operations; retain conditions, examples and important numbers. Integrate visual-only facts into the relevant section. Distinguish spoken claims, visible evidence and inference. Add timestamped screenshots only when useful.

For long videos, make substantive per-section notes from every chunk and its visual evidence, then merge, removing repetition while preserving qualifications and provenance. Consult original segments when resolving contradictions. Never merge prefix excerpts as if they covered entire chunks.

Use Chinese unless the user requests another language; retain technical names. The default opening horizontal Mermaid map should contain real concepts from the video. Do not invent quantitative data or generic filler nodes. Output the finished Markdown and a separate evidence record; do not wrap the entire document in a code fence.
